# AI 意图识别评测记录

本日志用于在修改 Prompt、工具 Schema 或模型后记录可复现的对比结果。真实评测不在 CI 中运行，也不由自动化测试触发。

## 统一约定

- 固定当前时间：`2026-10-30T09:00:00+08:00`（周五）。
- 固定用户时区：`Asia/Shanghai`。
- “本周”是周一到周日的自然周；“下周”是下一个自然周。
- “保质期一个月”按说明书示例统一为 30 天。
- 标题字段允许宽松匹配：期望标题与实际标题去掉空白、忽略大小写后，任一方包含另一方即通过。
- 时间字段按同一时刻精确比较，因此等价 UTC 偏移可以通过；金额和数量使用 Decimal 精确比较。
- 多动作按顺序比较工具列表和对应字段；额外或缺失动作会使该用例的意图判定失败。
- 追问只考核是否调用 `ask_clarification`，不限定具体问句。

## 运行方式

先在 `backend/.env` 或环境变量中配置真实模型密钥，再从项目根目录执行：

```bash
backend/.venv/Scripts/python.exe backend/evals/run_intent_eval.py \
  --confirm-real-api \
  --output backend/evals/latest-report.json
```

`--confirm-real-api` 是防止误消耗额度的显式开关。脚本使用独立内存 SQLite，只保存评测过程的 pending 解析记录和 LLM 日志，不触碰开发数据库，也不执行 confirm。

完整报告包含每条用例的错误字段和整体指标。`latest-report.json` 等运行产物不应提交 Git；需要长期保留的指标和结论摘录到本文件。
