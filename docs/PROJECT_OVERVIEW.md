# 万事屋项目概览

## 定位

万事屋是本地优先的个人生活效率平台，以统一 AI 入口连接生活管家、食材管家、收藏箱和旅行规划。Windows 桌面版面向普通使用者，Web 与 Docker 配置面向开发和自托管场景。

## 核心设计

- **AI 提议，人确认**：模型只负责理解和建议，确认后的写库由确定性业务代码执行。
- **数字让代码计算**：金额使用整数分，统计、预算、保质期和库存扣减不依赖模型心算。
- **模块化单体**：业务按模块划分，通过 service 层协作，避免跨模块直接操作数据表。
- **本地数据自主**：SQLite 保存账号和业务数据，支持备份与 Alembic 迁移。
- **配置不公开**：模型 Key 和本地环境文件不会进入源码仓库。

## 当前能力

- 生活：待办、日程、分类记账、提醒、月历和月度统计。
- 食材：库存、临期、购物、做菜扣减、空库存或有库存的 AI 菜谱。
- 收藏：网页正文提取、标签、全文搜索、AI 摘要和每周回顾。
- 旅行：每日安排、预算、AI 草稿、重排序和 Markdown 导出。
- 桌面：静默启动、内嵌后端、单实例、数据保留、代理修复和关闭确认。

## 技术与验证

- 后端：FastAPI、SQLAlchemy 2、Alembic、SQLite、Pydantic v2。
- 前端：Vue 3、TypeScript、Vite、Element Plus、Pinia。
- 桌面：Electron、PyInstaller、NSIS。
- 工程：pytest、Ruff、GitHub Actions、Docker Compose。

v1.0.2 发布前已通过 342 项后端测试、Ruff、前端生产构建，以及桌面启动、关闭取消、确认关闭和重复启动验证。GitHub 上的最新验证结果以 Actions 记录为准。

## 能力边界

主要业务流程已实现，不代表需求说明书中的所有未来版本均已完成。RAG 知识库、PDF/ICS 导出、地图与路线等增强项尚未实现。Docker 配置已提供，但当前开发机未做容器启动验收；真实模型质量、复杂动态网页抓取和不同设备的体验仍需持续验证。
