# 阶段 8.1：Windows 一键启动文件

## 应该打开哪个文件

在项目根目录双击 **`start-dev.bat`**。不要双击 `frontend/index.html`：本项目需要后端 API、数据库和前端开发服务共同工作，不是单文件静态网页。

脚本位置：`D:\cursor\wanshiwu-001\start-dev.bat`。

## 双击后发生什么

1. 检查后端虚拟环境、前端依赖和 npm 是否存在，缺少时给出安装提示，不擅自向 C 盘下载依赖。
2. 如果 `backend/.env` 不存在，从 `.env.example` 复制本地配置。
3. 执行 `alembic upgrade head`，确保数据库结构是最新版本。
4. 在独立窗口启动后端 `127.0.0.1:8000` 和前端 `127.0.0.1:5173`。
5. 等待前端启动后自动打开 `http://127.0.0.1:5173`。

使用时保留 `WanShiWu Backend` 与 `WanShiWu Frontend` 两个窗口，关闭它们即停止对应服务。首次进入页面可切换“创建账号”。

普通手动功能不需要模型 Key；使用 AI 前需自行编辑 `backend/.env`，填写服务商配置。该文件已被 Git 忽略，不会提交密钥。

## 验证方式

运行 `start-dev.bat --check` 只检查环境和迁移，不启动服务、不打开浏览器。本次已通过该模式验证：配置复制成功、Alembic 检查成功、脚本正常退出。

尚未通过双击脚本做新的完整浏览器人工验收，因此不把“检查通过”写成“所有页面已实拍验收”。
