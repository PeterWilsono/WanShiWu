# 阶段 5.4：食材管家 P0 前端页面

## 目标

把库存、FEFO 消耗、临期和购物清单接成用户可直接操作的 `/pantry` 页面。即使 AI 不可用，食材管家的核心功能也能独立使用。

## 页面结构

- **库存**：按冷藏、冷冻、常温分组，卡片显示数量、单位、购买日、过期日和备注；支持存放方式筛选、分页、入库、编辑和删除。
- **消耗**：从任一批次点击“消耗”，输入同名同单位总数量，由后端跨批次执行 FEFO，而不是只扣当前卡片。
- **临期**：可设置 0～365 天；已过期使用红色区域，即将到期使用橙色区域，显示相差天数。
- **购物清单**：支持添加、编辑、勾选完成、取消完成、删除和分页；完成项有删除线，菜谱来源会单独标注。

## 代码职责

- `frontend/src/types/pantry.ts`：食材、消耗结果、临期和购物项类型；数量以字符串传输，不在前端用浮点累计。
- `frontend/src/api/pantry.ts`：所有食材 P0 API 封装。
- `frontend/src/views/PantryView.vue`：三个标签页、表单对话框、加载/空/错误状态和操作反馈。
- 路由新增 `/pantry`，首页新增“食材管家”入口。

## 验证

`npm run build` 已通过，包括 vue-tsc 类型检查、Vite 生产构建和 PWA 构建。新增页面按路由懒加载；构建只有既有的大包体积提示。
