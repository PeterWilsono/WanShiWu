# 阶段 10.1：修复 AI 菜谱格式异常

## 原因

“清淡少油”只是普通偏好，不会导致格式错误。真正原因是旧解析器只接受一段完全纯净的 JSON：模型只要输出 Markdown 代码围栏、简短说明、思考块，或附加 difficulty 等字段，就会被拒绝。数字字符串也可能触发严格类型错误。

## 修复

- 新增统一 `parse_json_object()`，依次尝试纯 JSON、代码围栏和说明文字中的完整对象。
- 菜谱、收藏摘要和旅行草稿共用该解析器，减少不同模型输出风格造成的失败。
- 仅对 AI 输入边界兼容数字字符串并忽略附加说明字段；正式响应、库存扣减与业务规则仍使用严格模型。
- 保留一次纠错重试。数量非正、非法单位、菜谱数量错误和缺步骤等实质问题仍拒绝，不会生成看似成功但不可用的结果。

## 验证

- 新增“清淡少油 + 思考块 + 说明 + JSON 围栏 + 附加字段 + 数字字符串”一次通过测试。
- 菜谱、收藏 AI、旅行 AI 共 24 项专项测试通过。
- 未访问真实模型；真实模型的长期输出质量仍需在实际使用中观察。
