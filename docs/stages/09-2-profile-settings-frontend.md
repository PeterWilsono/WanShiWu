# 阶段 9.2：“我的”与模型设置页面

## 用户如何操作

1. 启动项目并登录，点击右上角头像。
2. 点击“我的”，可看到账号、当前模型和设置入口。
3. 进入“设置 → AI 模型”，选择“小米 MiMo”或“DeepSeek”。
4. 点击“获取 API Key”前往对应官方控制台，粘贴 Key；默认模型与 Base URL 已填好。
5. 点击“测试连接”，成功后勾选“设为我的当前 AI 模型”并保存。两家配置可同时保留，之后切换无需重新输入密钥。

## 页面内容

- 新增 `/me`：账号资料、当前模型、通用设置、分类管理和退出登录。
- 新增 `/settings`：AI 模型与通用偏好两个设置分类。
- 顶部头像菜单和移动端菜单均增加“我的”“设置”入口。
- AI 配置支持密钥密码框、留空保留旧密钥、模型名、官方 Base URL、连接测试、当前模型切换和删除配置。
- 通用设置支持时区、食材临期天数、每日 AI 调用上限，并保存到当前用户。
- README 改为页面配置指引；一键启动会检查新增加密依赖，缺少时安装到 D 盘项目虚拟环境，再执行迁移。

## 通俗说明

“测试连接”和“保存配置”是两个动作：测试用于确认当前填写的信息能否调用模型，保存用于让以后的 AI 功能使用它。测试成功但尚未保存时，旧配置仍然有效。

API Key 只存在页面内存和服务端加密配置中，不写浏览器 localStorage。连接测试会发起一次小额真实请求，因此可能产生服务商费用；开发自动测试不访问真实服务。
