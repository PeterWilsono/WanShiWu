# 阶段 3.7：首页待确认记录取消交互

## 改动内容

将首页确认卡片下方的“暂不处理”升级为“取消记录”，调用 `POST /assistant/records/{id}/cancel`。这会把服务端记录从 pending 改为 cancelled，而不只是隐藏前端卡片。

取消期间显示加载状态，并禁止同时点击确认；确认期间也不能取消，避免两个操作竞争同一条记录。只有服务端取消成功才清空卡片并提示“未写入任何数据”，失败则保留编辑内容和错误信息供重试。

## 验证

前端 TypeScript 检查、Vite 生产构建和 PWA 构建通过，无新增依赖，只有既有包体积提示。后端取消规则与异常场景的接口测试见阶段 3.6。
