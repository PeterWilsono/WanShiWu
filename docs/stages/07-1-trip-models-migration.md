# 阶段 7.1：旅行规划数据模型与迁移

## 目标

建立 `trips` 与 `trip_items`，为手动行程、每日条目、预算和拖拽排序提供数据基础。

## 设计

- 行程包含标题、目的地、可选开始日期、1～30 天、可选预算（整数分）、偏好、manual/ai 来源和 draft/confirmed 状态。
- 条目同时带 `user_id` 与 `trip_id`，读取时双重校验归属；日期从 1 开始，当天顺序非负。
- `start_time` 是当天本地时刻，不是 UTC 时间戳；`start_date` 是纯日期。
- 预算与成本使用 `BigInteger` 分，数据库检查非负，禁止浮点金额。
- 行程与条目延续 UTC 创建/更新时间和软删除。

## 迁移注意事项

Alembic 自动迁移把 FTS5 及其内部表误识别为“待删除表”，已人工移除这些危险操作；迁移只新增旅行表。开发库已升级到 `798a3e6a1aa6 (head)`。
