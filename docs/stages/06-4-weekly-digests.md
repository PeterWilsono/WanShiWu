# 阶段 6.4：收藏箱每周回顾

## 功能

新增 `GET /inbox/weekly-digests`，按周倒序返回当前用户的 Markdown 回顾、周一日期和收藏数量。

调度器每小时检查一次所有用户的本地时间。用户当地为周日 20 点时，汇总本周一 00:00 至下周一 00:00 创建的收藏，调用统一 LLM Client 生成回顾并写入 `weekly_digests`。

## 关键规则

- 时区使用 `ZoneInfo(user.timezone)`，不把服务器时区当用户时区。
- `(user_id, week_start)` 唯一约束加生成前检查，保证同一周幂等。
- 没有收藏时生成温和的空白周报，不调用模型。
- 单个用户生成失败会记录日志并继续其他用户，不会中断整个调度任务。
- 周报与提醒共用调度器，但各自任务独立、均限制 `max_instances=1`。

## 验证

新增周报与收藏回归共 10 项测试通过，覆盖：Fake LLM 生成、重复执行不重复调用、空周不调用、上海与 UTC 用户的触发差异、列表用户隔离、调度任务注册。Ruff 通过。

真实模型的周报质量与长期运行时的调度表现仍需配置模型后验收。
