# 阶段 6.2：收藏 CRUD、标签与全文搜索

## 本阶段能力

- `GET / POST /bookmarks`：分页列表、状态/标签筛选、保存链接。
- `GET / PATCH / DELETE /bookmarks/{id}`：详情、标题/备注/手动标签编辑、软删除。
- `GET /bookmarks/search?q=...`：标题、摘要、正文全文搜索。
- `GET /tags`：当前用户标签列表。

## 关键实现

- URL 只接受 HTTP/HTTPS，统一协议和域名大小写、移除片段，拒绝内嵌账号密码。
- 手动标签去重并复用同名标签，关联来源记为 `manual`；AI 标签后续可共存。
- 列表和搜索均带 `user_id` 与软删除条件，越权访问统一返回 404。
- 三字及以上查询使用 FTS5 trigram；1～2 字退化为 LIKE，通配符按普通字符转义。
- 更新和删除同步维护 FTS。删除后再次收藏同 URL 会恢复原记录、清空旧正文与标签，避免唯一约束冲突。
- `create_bookmark(..., commit=False)` 可供统一 AI 确认的多动作事务复用。
