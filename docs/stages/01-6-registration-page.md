# 阶段 1.6：注册页面与注册后自动登录

## 这一阶段解决什么问题

后端早已提供 `/auth/register`，前端 API 和 Pinia 也保留了注册方法，但登录页没有任何注册入口。新用户没有账号时直接登录，只会看到“用户名或密码错误”，无法通过页面完成首次使用。

本次补齐最后一小段前端流程：

- 新增 `/register` 路由，与 `/login` 共用一套视觉页面。
- 登录页显示“第一次来到万事屋？创建账号”。
- 注册页校验用户名长度、密码至少 8 位及两次密码一致。
- 注册成功后复用登录流程获取 JWT，直接进入原本要访问的页面。
- 重复用户名等后端错误直接显示在表单顶部。

## 实现方式

`LoginView.vue` 根据当前路由名切换登录或注册模式。两种模式复用用户名和密码字段，注册模式额外显示确认密码。提交时先调用注册接口，再调用现有 `authStore.login()`，不重复实现 Token 保存和当前用户恢复逻辑。

`frontend/src/router/index.ts` 增加 `register` 路由，并标记为 `guestOnly`：已登录用户不会反复进入注册页，未登录用户可以正常访问。登录与注册切换时保留安全的 `redirect` 查询参数。

## 验证

- `pytest backend/tests/test_auth_api.py -q`：10 项通过，覆盖注册、登录、重复用户名、错误凭据、Token 与关闭注册。
- `npm run build --prefix frontend`：TypeScript、Vite 和 PWA 构建通过；只有已有的包体积提示。

## 使用方式

打开 `/login` 后点击“创建账号”，填写用户名和两遍密码。注册成功会自动登录并进入首页；已有账号则直接登录。
