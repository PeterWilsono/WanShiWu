# 阶段 7.2：手动行程、预算、重排序与 Markdown 导出

## 已实现接口

- `GET / POST /trips`
- `GET / PATCH / DELETE /trips/{id}`
- `POST / PATCH / DELETE /trips/{id}/items[/{item_id}]`
- `PUT /trips/{id}/items/reorder`
- `GET /trips/{id}/export?format=md`

## 业务规则

- 创建行程可同时写入每日条目，未指定顺序时按当天递增加入。
- 详情返回扁平条目和 `daily_summaries`：每天日期、条目及小计。
- `planned_cents = 所有有效条目 cost_cents 之和`，预算余额和超支标记也由代码计算。
- 缩短行程天数前检查已有条目，避免把条目留在不可见日期。
- 条目同时校验用户、父行程与软删除状态；越权统一 404。
- 重排序必须提交当前行程的全部有效条目，ID 不可重复，同一天排序位置不可重复，日期不得超过总天数；所有变更只提交一次。
- 删除行程会同事务软删除全部条目。
- Markdown 包含标题、日期、每日安排、每日小计、总预算和核实提示；负余额按整数分正确格式化。
